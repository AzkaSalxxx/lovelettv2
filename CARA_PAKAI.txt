CARA PAKAI TEMPLATE LOVELOCK

1. Buka file config.js.
2. Ganti pin: "1234" menjadi PIN kamu sendiri.
3. Ganti text surat di bagian letterText.
4. Ganti 8 foto di folder assets/photos/ dengan nama:
   foto1.jpeg sampai foto8.jpeg
5. Ganti musik di folder assets/music/ dengan nama:
   music.mp3
6. Background bisa diganti di config.js:
   - Gradient: type: "gradient"
   - Warna: type: "color"
   - Foto: type: "image", value: "assets/background.jpg"
7. Upload semua file ke GitHub lalu deploy ke Vercel/Netlify.

Catatan: browser biasanya tidak mengizinkan autoplay musik sebelum user klik tombol, jadi musik mulai setelah klik Continue with Sound.
